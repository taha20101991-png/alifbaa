لعبة ألف باء — نسخة تجريبية مع إعداد صوت ماما
================================================

الإضافات:
- تبويب «صوت ماما».
- تسجيل صوت من الميكروفون ومعاينة التسجيل قبل إرساله.
- موافقة صريحة مطلوبة قبل رفع العينة.
- خادم Node.js يحفظ مفتاح الخدمة بعيدًا عن المتصفح.
- ربط مبدئي مع ElevenLabs لإنشاء صوت وتوليد الكلام.
- إذا لم يتم إعداد الخدمة، تستمر اللعبة بالصوت المتاح في المتصفح.

تنبيه:
هذه نسخة ويب تجريبية وليست APK ولا نسخة جاهزة للنشر على Google Play.
الاستنساخ الفعلي يحتاج حسابًا ومفتاح API صالحًا لدى ElevenLabs وقد يترتب عليه اشتراك أو تكلفة. راجع شروط المزود وسياسة الخصوصية قبل النشر.
لا تسجل أو ترفع صوت أي شخص دون موافقته الصريحة. هذه النسخة موجهة لصوت شخص بالغ موافق؛ لا تستخدم تسجيلات طفل لإنشاء نسخة مستنسخة من صوته.

التشغيل:
1) ثبّت Node.js حديثًا.
2) افتح Terminal داخل مجلد المشروع.
3) نفّذ: npm install
4) انسخ .env.example إلى ملف باسم .env.
5) ضع مفتاح ElevenLabs في ELEVENLABS_API_KEY داخل .env. لا تضع المفتاح في index.html ولا تشاركه.
6) نفّذ: npm start
7) افتح http://localhost:3000 في Chrome.
8) افتح «صوت ماما»، وافق على إرسال التسجيل، سجّل عينة واضحة، استمع إليها، ثم اضغط «إنشاء صوت ماما».

ملاحظات:
- الميكروفون يعمل عادة على localhost أو HTTPS.
- عند إنشاء الصوت، تُرسل العينة إلى خادمك ثم إلى ElevenLabs.
- معرّف الصوت محفوظ في المتصفح وفي ملف .mama-voice-id على الخادم.
- قبل الإنتاج يجب إضافة تسجيل دخول وصلاحيات وحدود استخدام وخيار حذف للصوت وسياسة خصوصية ومراجعة حماية البيانات.
- لا يوجد مفتاح API مضمّن في هذه الحزمة.
